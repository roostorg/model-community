Shieldstral evaluations

Community evaluation outcomes for Shieldstral. Contributions welcome via pull request.

When adding an evaluation, please note:

What you measured — safety performance (violative vs. benign), steerability (adherence to a supplied policy), or both. See the note in the parent README on why the distinction matters.
The policies used — steerable-model results depend heavily on how policies are phrased (length, specificity, whether they contradict the model's priors). Include the policy text or a link to it.
The dataset — what content, how much, and how labels were established.
Reproducibility — code or notebook where possible.
